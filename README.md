# Gladiators Battle Monitor

**Gladiators Battle Monitor** – простое Chrome‑расширение (Manifest V3) для игры **Gladiators**. Оно следит за страницей ожидания боя и уведомляет, когда начинается подготовка к бою.

**⚠️ В корне репозитория присутствует готовый ZIP‑архив `gladiators-battle-monitor.zip`** – его можно сразу загрузить в Chrome через **Load unpacked**.

## Что делает расширение
- При первом клике по иконке в панеле браузера включается мониторинг текущей вкладки.
- Каждые 5 секунд (по умолчанию) проверяется наличие блока `.task .content` с текстом **«Подготовка к бою»**.
- Если блок не найден – страница перезагружается и проверка продолжается.
- Если блок найден:
  - Останавливается цикл перезагрузок.
  - Появляется оверлей‑сообщение **«⚔️ Подготовка к бою обнаружена»**.
  - Проигрывается локальный звук `sounds/battle-start.mp3` (если включён).
  - Отправляется Chrome‑notification (если разрешено).
  - Значок расширения получает бейдж **B**.
- Повторный клик по иконке выключает мониторинг и убирает бейдж.

## Установка (для разработчиков)
1. Склонируйте/скачайте репозиторий.
2. Откройте Chrome → `chrome://extensions`.
3. Включите **«Режим разработчика»** (переключатель в правом‑верхнем углу).
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку репозитория.
5. Расширение появится в списке и будет готово к работе.

## Как пользоваться
1. Откройте страницу турнира в игре, например: `https://s2.gladiators.ru/xml/arena/tournaments.php?id=...`.
2. Нажмите на иконку расширения в правой части панели Chrome.
   - При включении появится бейдж **ON** и в консоли будет записано `Starting monitoring`.
3. Расширение будет проверять страницу каждые 5 сек.
4. Если появится блок подготовки к бою, вы увидите оверлей, звук и получаете системное уведомление.
5. Чтобы выключить мониторинг – нажмите по иконке ещё раз (бейдж исчезнет).

## Настройки (опционально)
Открыть страницу настроек можно через `chrome://extensions → Details → Extension options` или кликнув по ссылке **Options** в списке расширений.
На странице вы можете изменить:
- интервал проверки (минимум 3 сек);
- CSS‑селектор (по умолчанию `.task .content`);
- текст для поиска (по умолчанию `Подготовка к бою`);
- включить/выключить звук и системные уведомления.
Настройки сохраняются в `chrome.storage.local` и применяются сразу.

## Тестовая страница
В папке `test/` находится `test-page.html` – локальная страница для проверки:
1. Откройте её через `file:///.../test/test-page.html`.
2. Включите мониторинг, кликнув по иконке.
3. Нажмите кнопку **Показать подготовку к бою** – появится нужный блок.
4. Ожидайте оверлей, звук и уведомление – они должны появиться без реального сайта.

## Технические детали
- **Manifest V3**
- `background.service_worker` управляет кликом по иконке, состоянием, бейджем и уведомлениями.
- `content.js` реализует цикл `setTimeout`, детекцию и перезагрузку.
- Хранение настроек в `chrome.storage.local`.
- Разрешения: `storage`, `notifications`, `scripting`, `activeTab`.
- Host permissions ограничены только поддоменами `gladiators.ru`.
- Нет удалённого кода, `eval` и `<all_urls>`.

## Отладка
- Откройте **Консоль** на вкладке с игрой (Ctrl+Shift+J) – там будет выводиться отладочная информация, если в настройках `debugEnabled` включён.
- Для фонового скрипта откройте **Service Worker** в `chrome://extensions` → **Details** → **Service worker** → **Inspect**.

*Расширение лишь уведомляет о начале подготовки к бою и не осуществляет никаких действий в игре.*
